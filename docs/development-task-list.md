## 优先级建议

| 优先级 | 任务范围 |
| --- | --- |
| 高 | 当前用户机制、角色权限、学生加入课程、MainTask 发布流程、自动生成 SubTaskTemplate 和 StudentSubTask |
| 中 | StudySession 完整 CRUD、Dashboard 数据展示、SQL 视图接入、表单校验和错误提示 |
| 低 | Schedule 遗留功能处理、TaskDependency 遗留功能处理、文档美化和演示材料补充 |

## 核心联调链路

后续开发至少要保证下面这条主流程能够跑通：

```text
用户登录或切换身份
-> 学生加入课程
-> 教师发布 MainTask
-> 系统生成 SubTaskTemplate
-> 系统为已选课学生生成 StudentSubTask
-> 学生更新子任务进度
-> 学生记录 StudySession
-> Dashboard 展示进度和学习统计
```

## 接口对齐重点

| 功能 | 前端需要确认 | 后端需要确认 |
| --- | --- | --- |
| 登录/当前用户 | 页面入口、提交字段、登录后跳转地址 | Session 字段名、用户查询、角色判断 |
| 课程管理 | 表单字段、按钮显示规则、成功/失败提示 | Course CRUD、讲师权限、学生可加入课程查询 |
| 学生加入课程 | Join 按钮位置、重复加入提示 | Enrollment 创建、重复加入拦截、自动生成 StudentSubTask |
| MainTask 发布 | 表单字段、确认弹窗、是否显示编辑/删除 | 创建事务、AI/fallback、权限校验、不可编辑/删除规则 |
| 子任务进度 | 状态选择、备注、自定义字段表单 | 只允许修改当前学生自己的 StudentSubTask |
| 学习记录 | 时间选择、关联子任务、时长展示 | StudySession CRUD、动态计算时长、权限校验 |
| Dashboard | 不同角色看到的模块 | 统计 SQL、视图接入、数据范围限制 |
